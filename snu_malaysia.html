Principles of Separation of Powers

🏛️ Legislative Branch (Parliament)

  • Enactment and amendment of laws
  • Government audit and investigation
  • Budget review and approval

⚙️ Executive Branch (Government)

  • Law enforcement and implementation
  • Government administration and policy formulation
  • Public service delivery

⚖️ Judicial Branch (Courts)

  • Legal interpretation and application
  • Trials and dispute resolution
  • Constitutional review authority

Paper Documents (Classic)

  • Manual typing
  • Print → Copy → Distribution
  • Linear workflow
  • Difficulty in revision
  • Physical constraints

Digital Documents (1980s-1990s)

  • Word processor emergence (HWP, MS Word)
  • WYSIWYG editing
  • Easy digital storage and editing
  • Template utilization
  • Font and format diversification

Web Documents (1990s-2000s)

  • Hypertext (knowledge connection through links)
  • Multimedia integration
  • Global accessibility
  • Searchability
  • Knowledge democratization

Interactive Documents (2010s)

  • Executable code (R Markdown, Jupyter)
  • Reproducible research
  • Responsive interface
  • Explorable explanations
  • Literate programming realization

AI Intelligent Documents (2020s~)

  • Self-evolving documents
  • Conversational interface
  • Multimodal integration (text, voice, video)
  • Real-time fact-checking and verification
  • Personalized customized content

3 Stages of Document as Code

Stage 1: Document ≈ Code

  • Pure text: Written in Markdown
  • Version control: Track changes with Git
  • Platform independent: OS agnostic

Stage 2: Document ≈ Program

  • Executable code: R Markdown, Jupyter
  • Living data: Real-time computation
  • Reproducible research: Transparent process

Stage 3: Document ≈ Software

  • Interaction: Sliders, dropdown menus
  • Real-time response: Immediate changes to user actions
  • Web deployment: Global access via URL
